
# MSCS-634 Lab 2: KNN and RNN Classification

## Overview

This lab compares K-Nearest Neighbors (KNN) and Radius Neighbors
(RNN) classification algorithms using the Wine dataset from
scikit-learn.

The objective is to examine how different neighborhood parameters
affect classification accuracy.

## Dataset

- Dataset: Wine dataset (scikit-learn)
- Records: 178
- Features: 13 numerical attributes
- Target classes: 3
- Training set: 80%
- Testing set: 20%

## Technologies

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Implementation

1. Loaded the Wine dataset.
2. Examined feature statistics and class distributions.
3. Checked missing and duplicate records.
4. Split data into training and testing sets.
5. Trained KNN models using k = 1, 5, 11, 15, 21.
6. Trained RNN models using radii 350–600.
7. Calculated test accuracy for each configuration.
8. Generated accuracy plots and comparison charts.
9. Compared classification reports and confusion matrices.

## Results

### KNN

| K | Accuracy |
|---|---|
| 1 | 77.78% |
| 5 | 80.56% |
| 11 | 80.56% |
| 15 | 80.56% |
| 21 | 80.56% |

### RNN

| Radius | Accuracy |
|---|---|
| 350 | 72.22% |
| 400 | 69.44% |
| 450 | 69.44% |
| 500 | 69.44% |
| 550 | 66.67% |
| 600 | 66.67% |

## Key Findings

- KNN achieved higher accuracy than RNN.
- The best observed KNN accuracy was 80.56%.
- The best observed RNN accuracy was 72.22%.
- Increasing the RNN radius reduced test accuracy.
- Neighborhood selection significantly influenced predictions.

## Challenges and Limitations

- Choosing suitable neighborhood parameters.
- Handling observations with no neighbors in RNN.
- Understanding how feature scales affect distance calculations.
- Interpreting differences in class-specific model performance.

The original feature scale was retained to evaluate the
assignment's specified radius values. Future experiments
could investigate feature scaling and cross-validation.
